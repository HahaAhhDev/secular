Secular™

License compliance scanning for your codebase — offline fingerprinting against the full SPDX catalog, a compatibility rules engine, and optional AI adjudication for custom licenses.

Node.js ≥ 18 Zero runtime dependencies 727 SPDX license texts SARIF 2.1.0 Works offline — no API key for scanning
Source on GitHub Get started GitHub Packages

What it does

Fingerprint matching

Normalizes and shingle-hashes license text, matching full files and inline headers against the SPDX catalog by containment similarity. Popularity priors disambiguate near-duplicate families.

Rules engine

Detects copyleft in proprietary code, network copyleft in service stacks, non-open licenses, weak-copyleft obligations, and missing NOTICE files.

Manifest parsing

Reads dependency lists from npm, Cargo, Go, PyPI, RubyGems, and Packagist manifests.

CI-native output

Terminal, JSON, Markdown, and SARIF 2.1.0 for GitHub Code Scanning. Meaningful exit codes and a --strict gate.

AI adjudication (optional)

Custom or non-SPDX license texts go to your LLM (OpenAI, Anthropic, OpenRouter, or local Ollama) and the classification folds back into the rules engine. Requires an API key — plain scanning never does.

Offline first

The SPDX catalog is cached locally; scanning and scoring never need network access. A failed refresh falls back to the cached catalog.

Quick start

# Install (one-time npm setup for GitHub Packages)
github_token=$(gh auth token)   # or a PAT with read:packages
npm config set @hahaahhdev:registry https://npm.pkg.github.com
npm config set //npm.pkg.github.com/:_authToken="$github_token"
npm install -g @hahaahhdev/secular

# Scan any directory — no API key needed
secular scan /path/to/project

# CI gate with SARIF output
secular scan /path/to/project -f sarif -o license.sarif --strict

# Generate a THIRD-PARTY-NOTICES.md
secular notice /path/to/project

# Classify custom licenses with AI (the only command needing a key)
secular ai /path/to/project --api-key sk-ant-...

An install script is also available for Linux/macOS — see the README.

Rules & severities

RuleSeverityTrigger
COPYLEFT-IN-PROPRIETARYcriticalStrong copyleft (GPL) in a proprietary codebase
NETWORK-COPYLEFTcriticalAGPL/EUPL/OSL-style license in a network service
NON-OPEN-LICENSEcriticalSSPL, CC-BY-NC*, and other non-open licenses
PROJECT-LICENSE-CONFLICTerrorRoot LICENSE is copyleft but the project appears proprietary
PROJECT-LICENSE-UNFREEerrorRoot LICENSE restricts use
WEAK-COPYLEFTwarningMPL, EPL, CDDL, LGPL — disclose modifications
UNKNOWN-LICENSEwarningUnidentifiable license text — secular ai can classify it
MISSING-NOTICEinfoAttribution licenses present but no NOTICE file

Compliance score

A 0–100 score, penalized per finding: critical −30, error −15, warning −5, info −1. A clean scan scores 100; the score floors at 0.

Exit codes

CodeMeaning
0Clean — no findings at or above the threshold
1Findings present (any at/above the threshold with --strict, otherwise any critical)
2Usage or IO error
