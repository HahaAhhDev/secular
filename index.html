Secular™

License compliance scanning for your codebase. Offline fingerprinting against the full SPDX catalog, a compatibility rules engine, SARIF for CI, and optional AI adjudication for custom licenses.

curl -fsSL https://raw.githubusercontent.com/HahaAhhDev/secular/master/install.sh | bash
GitHub Documentation Releases

Why secular

Fully offline — 727 SPDX license texts cached locally; scanning never touches the network. Fingerprint matching — normalized shingle-based containment with popularity priors, so truncated and reformatted license files still match the right id. CI-native — SARIF 2.1.0, meaningful exit codes, and policy gates that fail builds on your terms.

Quick start

secular scan /path/to/project          # terminal report, no API key
secular scan . --ci -o license.sarif   # CI gate: strict + quiet + SARIF
secular notice .                       # THIRD-PARTY-NOTICES.md
secular ai . --api-key sk-ant-...      # optional: classify custom licenses

Policy gates

FlagFails when
--strictAny finding at/above --min-severity
--fail-on-category <c>Any license matches a category (e.g. strong-copyleft)
--fail-on-score <n>Compliance score is below n
--deny-license <id>A prohibited SPDX id appears anywhere
--allow-license <id>— (suppresses findings instead)

Rules & severities

RuleSeverityTrigger
COPYLEFT-IN-PROPRIETARYcriticalStrong copyleft (GPL) in a proprietary codebase
NETWORK-COPYLEFTcriticalAGPL/EUPL/OSL-style network copyleft
NON-OPEN-LICENSEcriticalSSPL, CC-BY-NC*, other non-open licenses
DENIED-LICENSEcriticalYour --deny-license policy
PROJECT-LICENSE-CONFLICTerrorCopyleft root LICENSE in an apparently proprietary project
WEAK-COPYLEFTwarningMPL, EPL, CDDL, LGPL
UNKNOWN-LICENSEwarningUnidentifiable text — secular ai can classify it
MISSING-NOTICEinfoAttribution licenses present, no NOTICE file

Score: 0–100. Critical −30, error −15, warning −5, info −1. Clean scan = 100.

Smart skip detection

Bundled runtimes (python-3.12.7/, jdk-21/, miniconda3/) and dependency trees (node_modules, site-packages) are auto-detected and skipped — their licenses aren't your compliance surface. Vendored licenses under vendor/ are scanned. Control it with --skip-mode ask (prompt once: ignore/scan), --scan-all, or --exclude.

Configuration

# .secularrc.json — CLI flags always override
{
  "denyLicense": ["SSPL-1.0"],
  "failOnCategory": ["strong-copyleft"],
  "strict": true
}

Generate scaffolds with secular --init and secular --init-ci.

Installing

The one-line installer above is the recommended route — no npm auth, no git, works on Linux, macOS, and Windows (Git Bash/WSL). Also available via npx @hahaahhdev/secular or from source. Full details in the installing guide.
